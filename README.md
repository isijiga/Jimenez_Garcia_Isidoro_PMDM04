
## Introducción: 
El proposito es crear una **guia interactiva** para mostrar el funcionamiento de la app SpyroTheDragon (Tarea 3 de PMDM). Muestra de fondo las diferentes pantallas mientras cambia la guia. Finalmente se crean dos EasterEgg en diferentes pantallas, las cuales se activan con dos eventos touch diferentes.
	
	
## Características principales:

La guia se activa en el primer usa de la app, una vez que se complete ya no vuelve a aparecer.  Esta guia incluye entre otras diferentes **animaciones** y **sonidos** al interacturar con la pagina.   

	
## Tecnologías utilizadas: 
Principalmente para el uso de la guia, he utilizado transparencias (alpha) en un Framelayout principal, el cual se va remplazando las diferentes Fragment de la guia. Se ha utilizado un Fragment por cada pantalla para poder realizar transaciones entre ellas.   

## Instrucciones de uso:
La aplicacion tiene activada la guia por defecto. Si se quiere volver a lanzar, se puede borrar las preferencias de la app desde el menu Ajuste, o descomentar la linea 62 de la clase MainActivity.java que establece a false el valor de la guia.
Una vez completada la guia, esta no volverá aparecer y se tendran que localizar los dos EasterEgg que contiene la app.
